chanx error types

Message could not be processed

https://chanx.dev/errors/internal-error

When it is sent

The server could not process the frame for a reason outside any handler, such as a consumer with no message handlers.

What to do

Treat the request as failed and report it to the server's operators.

Example

The payload of an error frame, an RFC 9457 problem details object:

{
  "type": "https://chanx.dev/errors/internal-error",
  "title": "Message could not be processed",
  "detail": "Failed to process message"
}

Every chanx implementation sends this type the same way. The protocol spec describes the whole error format.

All chanx projects are open source. Code, issues and discussions are on GitHub.
