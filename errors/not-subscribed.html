chanx error types

Not subscribed to topic

https://chanx.dev/errors/not-subscribed

When it is sent

A message was sent to a topic this connection has not joined.

What to do

Subscribe to the topic first, then send the message again.

Example

The payload of an error frame, an RFC 9457 problem details object:

{
  "type": "https://chanx.dev/errors/not-subscribed",
  "title": "Not subscribed to topic",
  "detail": "Not subscribed to 'room:other'"
}

Every chanx implementation sends this type the same way. The protocol spec describes the whole error format.

All chanx projects are open source. Code, issues and discussions are on GitHub.
