chanx error types

Subscription not allowed

https://chanx.dev/errors/unauthorized

When it is sent

The topic's authorization hook refused the subscription.

What to do

Do not retry with the same credentials. Subscribe to a topic this connection may join.

Example

The payload of an error frame, an RFC 9457 problem details object:

{
  "type": "https://chanx.dev/errors/unauthorized",
  "title": "Subscription not allowed",
  "detail": "Not allowed to subscribe to 'room:secret'"
}

Every chanx implementation sends this type the same way. The protocol spec describes the whole error format.

All chanx projects are open source. Code, issues and discussions are on GitHub.
