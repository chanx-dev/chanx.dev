Error types

A chanx server answers a frame it cannot handle with an error frame whose payload is an RFC 9457 problem details object. Its type is one of the URIs below, the same in Python, TypeScript and Go. Branch on type; title and detail are for people.

Type, under https://chanx.dev/errors/Title
validation-failedMessage failed validation
invalid-jsonFrame is not valid JSON
handler-failedMessage handler failed
internal-errorMessage could not be processed
unknown-topicUnknown topic
unauthorizedSubscription not allowed
not-subscribedNot subscribed to topic

The protocol spec describes the whole error format.

All chanx projects are open source. Code, issues and discussions are on GitHub.
